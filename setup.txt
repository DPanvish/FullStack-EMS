================================================================================
QuickEMS — Enterprise Employee Management System
Professional Setup & Operations Guide
================================================================================

OVERVIEW
--------
QuickEMS is a full-stack human resource management and operational suite:
- client: Modern React 19 + Vite 8 frontend styled with Tailwind CSS 4, featuring
  TanStack Query v5 state management and HTTP-Only cookie security.
- server: Express 5 + MongoDB backend API featuring JWT authentication,
  cookie-parser session handling, Multer document uploads, and Inngest serverless
  background workflow orchestration.


PREREQUISITES
-------------
Ensure the following tools are installed on your environment before starting:
1. Node.js (v18.0.0 or higher recommended, LTS preferred)
2. npm (v9.0.0 or higher) or yarn / pnpm
3. MongoDB database connection URI (local instance or MongoDB Atlas cluster)
4. (Optional) SMTP credentials (e.g. Brevo / Gmail) for live email dispatch
5. (Optional) Inngest CLI for local background workflow testing


SERVER SETUP & CONFIGURATION
----------------------------
1. Navigate to the server directory:
   cd server

2. Install backend dependencies:
   npm install

3. Configure environment variables:
   Copy the example template to create your `.env` file:
   (Windows PowerShell):
   Copy-Item .env.example .env
   (Linux/macOS):
   cp .env.example .env

   Populate `server/.env` with your credentials:
   ----------------------------------------------------------------------
   PORT=4000
   MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/ems
   JWT_SECRET=super_secret_jwt_key_at_least_32_characters_long
   ADMIN_EMAIL=admin@example.com

   # SMTP Configuration (Optional for notifications)
   SMTP_USER=your_smtp_user
   SMTP_PASS=your_smtp_password
   SENDER_EMAIL="QuickEMS Notifications <noreply@yourdomain.com>"

   # Inngest Background Jobs (Optional for cloud, leave blank for local dev)
   INNGEST_EVENT_KEY=
   INNGEST_SIGNING_KEY=
   ----------------------------------------------------------------------

4. Seed the initial Super Admin account:
   npm run seed

   Default Generated Admin Credentials:
   - Email:    admin@example.com (or value defined in ADMIN_EMAIL)
   - Password: admin@123
   * Note: Change this temporary password upon initial login via the Settings portal.

5. Start the backend server:
   npm run dev     # Starts server with Nodemon (auto-reload) on port 4000
   # or
   npm start       # Production startup


CLIENT SETUP & CONFIGURATION
----------------------------
1. Navigate to the client directory:
   cd ../client
   # or from repository root:
   cd client

2. Install frontend dependencies:
   npm install

3. Configure environment variables:
   Copy the example template to create your `.env` file:
   (Windows PowerShell):
   Copy-Item .env.example .env
   (Linux/macOS):
   cp .env.example .env

   Ensure `client/.env` points to your backend API:
   ----------------------------------------------------------------------
   VITE_BASE_URL=http://localhost:4000
   ----------------------------------------------------------------------

4. Start the frontend development server:
   npm run dev

   The application will run locally at:
   http://localhost:5173/


INNGEST BACKGROUND WORKFLOWS (LOCAL DEV)
----------------------------------------
QuickEMS employs Inngest for scheduled shift auto-checkouts, clock-out alerts,
and automated morning absent notifications.

To execute background functions locally:
1. Ensure your backend server is running on port 4000.
2. In a separate terminal window, launch the Inngest local dev server:
   npx inngest-cli@latest dev -u http://localhost:4000/api/inngest
3. Open http://localhost:8288 to access the local Inngest function dashboard,
   inspect event triggers, and replay background steps.


CLIENT NPM SCRIPTS
------------------
- npm run dev      : Launches the Vite local dev server with Hot Module Replacement (HMR).
- npm run build    : Generates an optimized production bundle in the `dist` folder.
- npm run preview  : Locally serves the production build for testing before deployment.
- npm run lint     : Executes ESLint against client source code for quality assurance.


SERVER NPM SCRIPTS
------------------
- npm run dev      : Launches the Express API with Nodemon watching for file changes.
- npm start        : Runs the production server via Node.js runtime.
- npm run seed     : Provisions the primary organization administrator in MongoDB.

Backend (`server/package.json`):

- inngest (^4.21.1)              : Event-driven background jobs & cron workflow engine.
- dotenv (^18.0.1)               : Runtime environment configuration loader.


KEY API ENDPOINTS
-----------------
- GET  /                         : Health check endpoint.
- POST /api/auth/login           : User authentication (sets HTTP-Only cookie).
- POST /api/auth/logout          : Terminates session (clears cookie).
- GET  /api/auth/session         : Validates active session and returns authenticated user.
- GET  /api/dashboard            : Aggregated organizational stats & metrics.
- /api/employees                 : Employee CRUD directory & user creation.
- /api/profile                   : Personal employee profile viewing & edits.
- /api/attendance                : Real-time clock-in/out & shift history tracking.
- /api/leave                     : Leave application, review, and status tracking.
- /api/payslips                  : Automated monthly payroll calculation & history.
- /api/inngest                   : Inngest serverless endpoint for automated background jobs.


VERIFYING THE INSTALLATION
--------------------------
1. Confirm backend is operational by visiting:
   http://localhost:4000/ -> Expected: "Server is working"
2. Confirm frontend is running at:
   http://localhost:5173/
3. Sign in as Super Admin (`admin@example.com` / `admin@123`).
4. Create an employee under the Employees portal.
5. In an incognito window, sign in using the new employee credentials to test
   the Employee Portal (Attendance clock-in, leave application, profile view).
