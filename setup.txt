Setup Guide
===========

This project contains two apps:

- `client`: React + Vite frontend.
- `server`: Express + MongoDB backend API.

Prerequisites
=============

- Node.js 18 or newer.
- npm.
- MongoDB connection string.
- SMTP credentials if email notifications are required.

Client Setup
============

From the repository root:

```bash
cd client
npm install
npm run dev
```

The client runs at `http://localhost:5173/` by default. If port `5173` is unavailable, Vite prints the alternate URL.

Client Scripts
==============

```bash
npm run dev      # Start the Vite development server.
npm run build    # Create a production build.
npm run preview  # Preview the production build locally.
npm run lint     # Run ESLint against the client source.
```

Server Setup
============

From the repository root:

```bash
cd server
npm install
```

Create `server/.env`:

```env
PORT=4000
MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>/<database>
JWT_SECRET=<strong-random-secret>
ADMIN_EMAIL=admin@example.com

SMTP_USER=<smtp-user>
SMTP_PASS=<smtp-password>
SENDER_EMAIL=<sender-email>

INNGEST_EVENT_KEY=<inngest-event-key>
INNGEST_SIGNING_KEY=<inngest-signing-key>
```

Keep real secret values out of committed files. The backend authentication code expects `JWT_SECRET`.

Server Scripts
==============

```bash
npm run dev    # Start the server with nodemon.
npm start      # Start the server with node.
npm run seed   # Create the initial admin user.
```

The API runs at `http://localhost:4000/` by default.

Admin Seed
==========

After configuring `server/.env`, run:

```bash
cd server
npm run seed
```

The seed script creates an admin user from `ADMIN_EMAIL` with the temporary password `admin@123`. Change this password after logging in.

Useful API Paths
================

- `GET /`: Server health message.
- `/api/auth`: Login, session, and password routes.
- `/api/employees`: Employee management routes.
- `/api/profile`: Profile read/update routes.
- `/api/attendance`: Attendance routes.
- `/api/leave`: Leave request routes.
- `/api/payslips`: Payslip routes.
- `/api/dashboard`: Dashboard route.
- `/api/inngest`: Inngest endpoint.

Implementation Notes
====================

- The client currently uses sample data in `client/src/assets/assets.jsx`.
- The server already includes API routes, controllers, models, middleware, and database connection code.
- Connect the client pages to the API before using the app with live data.
